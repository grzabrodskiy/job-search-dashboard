# Update Memory

Use this command after a meaningful job-search session or when new durable information is discovered.

1. Read `workflows/memory_protocol.md`.
2. Update `memory/agent_memory.md` for durable facts and lessons.
3. Update `memory/search_history.md` if a search report was created.
4. Update `memory/improvements.md` for proposed or completed process changes.
5. Keep application statuses in `tracking/applications.md` and leads in `tracking/leads.md`; do not duplicate tracker details into memory.
